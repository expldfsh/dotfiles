# dotfiles

Personal configuration files for macOS, Arch Linux and WSL.

- `mac/` mirrors the macOS home directory, including Homebrew Fish, Kitty, Zsh, Vim and Neovim settings.
- [Arch Linux / Niri](linux/README.md) contains the Linux home-directory overlay, package lists and installer. Preview it with `bash linux/install.sh --plan`.
- `WSL/` contains the separate Windows Subsystem for Linux setup.
- `wallpaper/` contains shared wallpaper assets.
